# 🦁 草原进化模拟器 Savannah Evo

一个零依赖、单文件的生态与进化模拟器：草—兔—狼三级食物网，无性繁殖 + 随机变异，观察 Lotka-Volterra 种群振荡与自然选择塑造基因。

## 使用方法

- **本地运行**：直接双击打开 `index.html` 即可（无需服务器）。选择预设 → 按 ▶ 开始 → 倍速调到 8×/16× 看长期演化。
- **Android 版**：`../EvolutionSim-Android` 工程打包为 WebView APK，完全离线、零权限。构建产物为工作区根目录 `EvolutionSim-v1.0.0.apk`（与物理实验沙盒同一套构建工具链与 Keystore）。

## 世界规则

**草**：按 16px 网格分布，逻辑斯蒂生长（`db = r·b·(1-b)`）+ 从茂盛格向贫瘠格蔓延。每格满生物量含 40E 能量。

**动物**（兔/狼共用一套模型，参数分化）：
- **能量 E 是唯一货币**：吃草/吃兔获得，代谢消耗（基础 + 速度项），归零即饿死
- **有丝分裂繁殖**：E ≥ 80%上限 且冷却结束（兔 20s / 狼 45s）→ 能量对半分裂出子代
- **遗传**：每个基因 85% 概率 = 亲代 ± 5% 高斯小扰动，15% 概率 ±20% 大变异
- **基因表**：speed（速度，代谢贵）、cap（能量上限=耐饿，繁殖阈值水涨船高）、vision（视野，代谢微增）——每个基因都有代价，形成适应性权衡

**捕食关系**：
- 兔惊逃冲刺 ×1.35（狼基础速度 75 < 兔 60×1.35=81——逃得掉的才活命，速度成为选择压力）
- 捕获率随速度差衰减（贴脸非必中，猎物可挣扎）
- 狼捕食后 10s 消化冷却；幼崽 12s 保护期
- 狼饥饿远征：能量 <40% 时视野 ×1.6（饥饿驱动远行觅食）
- 捕食能量转化率 0.8（UI 可调）

**代谢**：`metabK × 体型系数(狼1.6) × (1 + 0.02·speed·moving²)`——快 = 贵。

**数量上限（分物种）**：兔 450 / 狼 80。狼封顶即压制力上限，防止捕食者超调把猎物吃光（离散随机 LV 系统的经典崩溃模式）。

## 标定结果（已验证）

`node test.mjs` —— 15 项数值/生态断言全过。多种子统计：

- **经典草原（默认，草生长率 0.04）**：600s 五种子全部三物种共存（5/5），种群稳定高位
- **进化证据**：600s（~30 代）后兔群平均速度从初始 60 演化到 72~116（狼压下快兔存活）——进化曲线肉眼可见
- **野生振荡（草生长率 0.028）**：草供给临界 → 完整 Lotka-Volterra 振荡（兔 450→低谷 100~200→反弹；狼跟随滞后波动），约 60% 种子可持续振荡，其余崩溃——演示生态脆弱性
- **无狼对照**：兔顶到容纳量 450 后停滞——证明捕食是振荡的来源

## 预设实验

| 预设 | 内容 | 观察点 |
|:---|:---|:---|
| 经典草原 | 草 60% + 40 兔 + 8 狼（草生长率 0.04） | 稳态共存 + 进化曲线 |
| 野生振荡 | 草生长率 0.028（草供给临界） | Lotka-Volterra 振荡、相位滞后、崩溃风险 |

| 军备竞赛 | 狼初始提速 105 | 兔 speed 基因代际攀升 |
| 无狼对照 | 无捕食者 | 兔停在容纳量，无振荡 |

## 界面

- 主画布：草色深浅 = 生物量；点选动物看基因卡（速度/耐饿/视野/能量条/代数）
- 种群动态图：草/兔/狼三线（兔狼 ×10 显示）
- 进化曲线：种群平均基因值随时间（速度/耐饿/视野三个标签页）——**进化方向肉眼可见**
- 倍速 0.5×~16×；投放工具（点击画布放兔/狼）

## Android APK 打包（WebView 壳）

`../EvolutionSim-Android` 工程为本项目的 Android 壳（零依赖、零权限、完全离线）：

```powershell
$env:GRADLE_USER_HOME  = "D:\18389\Documents\deepseek工作区\.gradle"
$env:ANDROID_USER_HOME = "D:\18389\Documents\deepseek工作区\.android"
$env:JAVA_HOME         = "C:\Android\jdk-17\jdk-17.0.13+11"
$env:ANDROID_HOME      = "C:\Android"
$env:PATH              = "C:\Android\jdk-17\jdk-17.0.13+11\bin;$env:PATH"
cd "D:\18389\Documents\deepseek工作区\EvolutionSim-Android"
.\gradlew.bat clean assembleRelease --no-daemon
Copy-Item "app\build\outputs\apk\release\app-release.apk" "D:\18389\Documents\deepseek工作区\EvolutionSim-v1.0.0.apk" -Force
```

更新网页内容后：把新版 `index.html` 复制到 `EvolutionSim-Android\app\src\main\assets\` 再重新打包即可。
签名复用 NovelCraft 的 Keystore（`keystore/novel-release.keystore`，别名 `novel`）。
